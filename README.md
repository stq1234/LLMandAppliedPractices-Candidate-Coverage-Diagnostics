# 候选覆盖与部署诊断

独立、离线的候选池回放工具，用于分解候选覆盖、答案归并、验证器排序与生成截止时间的影响。输入快照包含作业6固定测试集上的脱敏译文、既有筛选与评审标签，以及实际逐请求生成耗时；运行时不依赖作业6目录、网络、模型或 API。

本项目是**事后诊断**。作业6的候选、自动评价及部分汇总已经被查看和使用，因此本项目的分析不是新的独立评测，也不将样本划分描述为事前留出集。观察单位为24个任务、20个文档／最小对照组和两个历史运行；所有区间按20组聚类重采样。

## 复现

需要 Python 3.12 及 `requirements.txt` 中的 Matplotlib。统计、重放与校验仅使用 Python 标准库；Matplotlib 用于导出图表。

```powershell
python -m pip install -r requirements.txt
python run_diagnostics.py
```

无图运行：

```powershell
python run_diagnostics.py --no-plots
```

脚本会重建 `results/` 中的 CSV、JSON 结果和 `figures/` 中的 PNG/SVG 图。`results/validation.json` 对行数、匿名映射、耗时键、盲评材料等进行断言；任一条件不满足时程序以错误退出。整个流程不访问其他文件夹或网络。

## 诊断范围

* **归并**：在同一任务、运行、采样策略和候选前缀上比较原始字符二元组 F1 medoid、归一化去重后的 medoid，以及以 0.90 相似度连通分量投票的 medoid。三个选择器都不读取评审标签。覆盖率和独立评审结果仅用于结果评价。
* **高分尾部**：按既有筛选器 adequacy、fluency 和候选顺序重排每个八候选池，检查排名第一及后续排名的独立评审可用率，并统计筛选器高分可用而独立评审不可用的候选。评分离散且并列很多，秩次仅由固定的并列规则确定，不解释为校准概率。
* **采样分布**：在相同任务和运行下，配对比较普通与多样化提示形成的八候选池。变化项是原实验定义的表达组织策略；温度、每个任务的候选预算和评价口径保持相同。主要指标为可用候选覆盖、候选数量、有效去重数量、池内相似度、筛选选中成功率和 medoid 成功率。
* **截止时间**：根据历史单个生成请求实际耗时，按候选索引重放 1 个或 6 个并发槽位，在 6、12、18、24、30 秒截止点统计完整候选和选择结果。只计生成阶段；未计入请求排队、跨任务竞争、筛选器、人工复核和后续评审耗时。单槽位是串行情形；六槽位是每个池独享六个槽位的理想化情形，不代表作业6当时的端到端墙钟时间。

汇总文件和指标定义见 `results/summary.json`、`results/validation.json` 及对应 CSV。`figures/` 图表由这些结果确定性重绘。

## 当前实测摘要

K=8 时，ordinary 池覆盖率为95.8%，筛选选中成功率为91.7%；diverse 对应为97.9%与93.8%。配对成功率差为+2.1个百分点，聚类 bootstrap 95%区间为0至+6.3个百分点。diverse 池内平均相似度低1.3个百分点，区间为−2.5至−0.4个百分点；有效可用译文数差为+0.27，区间为−0.02至+0.52。

固定候选池 K=8 后，归一化去重 medoid 改变9.4%的选择，但总体成功率不变；0.90近重复多数簇改变18.8%的选择，成功率差为+1.0个百分点，区间为0至+3.1个百分点。选择器排序第一的候选成功率为92.7%，排名2–8的平均成功率为89.6%；排序第一中有7份候选虽被既有选择器判为可用、却未通过独立自动评审，现有证据不支持“高分尾部普遍更差”。

6秒截止时，串行模拟在 ordinary／diverse 池均平均完成1.60份候选，筛选成功率分别为87.5%和89.6%；每池独享6并发槽位时分别平均完成6.88和6.81份，成功率为91.7%和93.8%。这些是基于历史单请求耗时的调度模拟，不能解释为线上端到端延迟。历史快照的最大预算为8，因此不构造或声称实测32候选结果。

## 数据来源和隐私处理

主快照从作业6的固定测试集生成：`results/analysis/candidate_metrics.csv` 提供候选文本、选择分数和逐项独立评审状态；成功生成请求记录提供 `seconds`、token 数、结束原因和重试计数。24个原任务标识和20个组标识均替换为 `case_NNN`、`cluster_NNN`，历史种子映射为 `run1`／`run2`。原始源文和术语表、来源标题与 URL、提示词、API 端点、请求体、认证材料、哈希、响应 ID、时间戳和模型身份均未复制到主快照。

`data/review_batch.jsonl` 是四条匿名任务、八份无标签译文的独立复核材料。主代理已用 GPT-6.2 Astra 完成盲评，结果原文保存在 `data/astra_review.json`；`data/review_index.json` 将复核编号及 A/B 输出映射回匿名候选编号，不包含评审标签。本项目的程序不把这四组目的性小样本人工判断并入全池统计。八个输出位置中有一对译文相同，共七种不同的源文／译文组合。复核批次中的源文仅用于理解输出，与主分析快照分开保存。

课程题目及讲义备注的定位记录见 `LECTURE4_PROMPT.md`。数据行数和字段说明见 `data/manifest.json`。
